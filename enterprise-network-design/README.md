
# Enterprise Network Design – VLAN & Routing Lab

## Objective
Design and implement a small enterprise network with multiple VLANs,
inter-VLAN routing, and dynamic routing to simulate a real business environment.

## Tools Used
- Cisco Packet Tracer
- Cisco Routers and Switches

## Network Components
- 2 Routers
- 2 Layer 2 Switches
- Multiple PCs
- VLANs: 10 (Admin), 20 (HR), 30 (IT)

## Configuration Summary
- VLAN creation and assignment
- Inter-VLAN routing using Router-on-a-Stick
- OSPF for dynamic routing
- DHCP for automatic IP assignment

## Verification
- Successful ping between VLANs
- Routing table verification
- End-to-end connectivity confirmed
